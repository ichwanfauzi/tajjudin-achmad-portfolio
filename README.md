# 💼 Tajjudin Achmad - Personal Portfolio Web

> Website portofolio interaktif dan responsif untuk menampilkan profil profesional, rekam jejak proyek, serta keahlian Tajjudin Achmad.

---

## 🌟 Fitur Utama

- 📱 **Fully Responsive:** Tampilan optimal di perangkat desktop, tablet, dan *mobile*.
- 🖼️ **Showcase Proyek:** Galeri karya dan proyek yang dikerjakan beserta detail *tech stack*.
- 📩 **Formulir Kontak:** Fitur interaktif untuk menghubungkan pengunjung langsung dengan pemilik portofolio.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript / React / Tailwind CSS
- **Deployment:** GitHub Pages / Vercel

---

## 🚀 Cara Menjalankan

```bash
git clone [https://github.com/ichwanfauzi/tajjudin-achmad-portfolio.git](https://github.com/ichwanfauzi/tajjudin-achmad-portfolio.git)
cd tajjudin-achmad-portfolio
# Buka index.html di browser atau jalankan 'npm run dev'
